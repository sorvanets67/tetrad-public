# Работа над «Тетрадью»

Это приложение для одного пользователя на Linux с графическим планшетом. Интерфейс на русском. Статические HTML/CSS/JS без сборки и внешних зависимостей. Не переносить проект на фреймворк без необходимости.

Сначала прочитай README.md. Запуск: python3 serve.py (локальный сервер без кэширования файлов приложения). Проверки: node --test tests/core.test.mjs.

Документ хранится в IndexedDB, формат version:1. Не меняй формат без миграции и проверки импорта старых резервных копий. Не очищай пользовательские записи. Не отправляй заметки на сервер без запроса пользователя.

Главное: надёжное письмо пером, сохранность данных и редактируемые фото/штрихи. Экспорт JSON должен содержать все страницы и встроенные фото. Нажим проверять на настоящем планшете; не обещать поддержку по результату теста мышью. Сейчас ластик удаляет целый штрих.

Перед отчётом запускай проверки изменённой логики. Сохраняй изменения в Git. .openai/hosting.json относится к размещённой версии; при локальной работе не публикуй без соответствующего запроса.
